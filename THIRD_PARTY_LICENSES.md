# Third-Party Licenses

This project is built directly on the LikeC4 packages, React, Vite, and everything they in turn depend on. This file acknowledges every third-party package in the dependency tree pinned by `pnpm-lock.yaml` (production and development dependencies both - anything installed to build or run this project), grouped by license.

Regenerate this file's data at any time with:

```bash
pnpm licenses list --long --json
```

That command only reads each package's own `"license"` field, though - a
package that omits it (like `khroma`, see the note under its entry) gets
reported as "Unknown" even when it actually ships a license file, so any
"Unknown" result from a regeneration is worth checking by hand against the
installed package before assuming there really is none.

This app's own license is in [LICENSE](./LICENSE) (MIT) - unrelated to the licenses below, which apply to the packages it depends on, not to this project's own code.
