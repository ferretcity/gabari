**[Gabari](https://github.com/ferretcity/gabari)** — a browser-only, no-backend
visual editor for [LikeC4](https://likec4.dev) diagrams. Model your
architecture, capture the decisions behind it, and turn both into a report or
a slide deck — all client-side, nothing to host.
